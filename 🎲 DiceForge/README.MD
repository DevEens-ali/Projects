# 🎲 DiceForge

### Full-Stack Dice Rolling & Simulation Platform

> A modern, interactive and extensible dice simulation platform built with **HTML, CSS, JavaScript, Python, FastAPI, and PostgreSQL**.

DiceForge is a full-stack web application that allows users to roll different types of dice, view animated results, track their rolling history, and analyze statistics through a clean and interactive interface.

The project is designed not only as a dice simulator, but also as a practical demonstration of **modern full-stack development, REST APIs, backend architecture, database integration, and frontend-backend communication**.

---

## ✨ Features

### 🎲 Dice Rolling

- Roll one or multiple dice
- Support for different dice types
- Randomized dice results
- Display individual dice results
- Automatically calculate the total
- Smooth dice rolling animation
